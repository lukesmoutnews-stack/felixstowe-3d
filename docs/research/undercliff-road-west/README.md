# Undercliff Road West: reference photos

The user supplied these Google Street View captures (June 2022) on 12 Oct 2026, as the reference for modelling the seafront frontage. They are kept here for modelling only and are not published with the game. The user notes that the Spa Pavilion's red trim has since been repainted blue.
